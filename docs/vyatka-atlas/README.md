# Вятский исторический атлас — R08 WEB

Единый статический веб-проект по историческим находкам современной Кировской области и сравнительным сведениям исторической Вятской губернии.

## Состав
- `index.html` — карта на OpenStreetMap / спутниковой подложке Esri, карточки, фильтры, поиск по объектам, топонимам и документам, экспорт CSV, JSON, GeoJSON, XML.
- `data.json` — 109 записей реестра, 55 библиографических записей документов, 82 свидетельства с номерами страниц/абзацев, 31 исторический топоним, статусы просмотра 14 поздних томов, 17 дополнительных библиографических ссылок.

## Принцип достоверности
- 15 записей с координатами, 94 не локализованы. Не рисовать для 94 пунктов точку центра села вместо места находки.
- Каталожные координаты метеоритов — не подтверждённые места наблюдаемого падения.
- Точки наблюдений болидов обозначают город наблюдения, не район падения.
- Объекты бывшей Вятской губернии вне современной Кировской области — сравнительный слой.
- Некоторые тома исследованы лишь по оглавлениям и отдельным страницам. Полного сквозного исследования всех 55 PDF нет.

## Просмотр на любом компьютере через интернет
Включить GitHub Pages в Settings → Pages данного репозитория:
1. Build and deployment → Source: Deploy from a branch.
2. Branch: main, Folder: / (root) → Save.
3. После активации открыть: https://sergeysh76.github.io/Lesson1/docs/vyatka-atlas/

Внешние файлы Leaflet, OSM и Esri требуют доступа к интернету. Сами 109 записей хранятся вместе с сайтом и не требуют авторизации в Google Таблицах.

## Развитие
Вносить уточнения координат с источником и фиксировать границы неопределённости как доказательно обоснованные полигоны. Новые PDF не нужно прикладывать к сайту, достаточно стабильной карточки НЭБ, страницы PDF и краткой выдержки/пересказа.
