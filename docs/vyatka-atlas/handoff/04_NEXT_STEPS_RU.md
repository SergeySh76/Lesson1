# План R12 и контрольный перечень

1. Открыть актуальную страницу R11 в обычном браузере; проверить нажатия по нескольким обычным и сгруппированным меткам, передачу выбора в правый список, прокрутку и отображение полного текста.
2. Проверить отсутствие popup при наведении и курсор-стрелку; не возвращать сценарий R10 с hover-popup.
3. Проверить отдельные вкладки «Клады» (43), «Исследования» (28), «Документы» (55), «Топонимы» (31), легенду и адаптацию смартфона.
4. Сделать независимое сравнение Google Таблицы R11 с GitHub data.json по ID, страницам, датам и статусу.
5. Провести источниковедческий контроль списков денежных комплексов: Мокерова (2012) — 27 опубликованных случаев XVII–начала XVIII в.; Мокерова/Тарасов (2020) — 37 комплексов XVIII в. Следить за дублями и сомнительными комплексами.
6. Уточнить исторические названия и места по дореволюционным картам с широким покрытием современной Кировской области; старая Вятская губерния должна оставаться отдельным сравнительным слоем.
7. Сопоставить палеонтологию, археологию и сведения по метеоритным явлениям. Обозначать даты находок и события раздельно.
8. Для исправлений готовить новую ревизию R12 без утраты уже подтверждённых 151 ID. Добавлять исходные страницы/абзацы и сохранять историю изменения.
9. После окончания этапа выдавать краткий статус, ссылки, ZIP с полным отчётом. На Windows распаковывать в G:\AI_ENGINEERING\VYATKA_ATLAS\, сохранять все результаты рядом с запускаемым CMD.

Ограничения: 55 PDF ещё не прочитаны целиком; у 136 объектов используются только приблизительные навигационные ориентиры; исходные PDF в этом архиве не включены. Реальный просмотр браузера и запуск SQLite нужно подтвердить фактическим тестированием.
