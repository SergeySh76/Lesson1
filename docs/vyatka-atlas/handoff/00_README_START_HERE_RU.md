# Вятский исторический атлас — передача проекта R11

**Дата состояния:** 29 октября 2026 года. **Язык:** русский.
**Папка на текущем компьютере:** G:\AI_ENGINEERING\VYATKA_ATLAS\
**Имя подпапки внутри ZIP:** VYATKA_ATLAS_R11_HANDOFF

Это комплект для переноса исследования и сайта в новый чат без повторения выполненной работы.

## Как работать с архивом

1. Распаковать архив в G:\AI_ENGINEERING\VYATKA_ATLAS\. Появится отдельная папка VYATKA_ATLAS_R11_HANDOFF.
2. Дважды щёлкнуть OPEN_ATLAS.cmd — открывается локальная копия сайта в браузере с интернетом. Сайт использует HTML и Leaflet/OpenStreetMap/Esri; ничего через pip ставить не нужно.
3. При необходимости создать настоящую SQLite-базу и XML/SQL/GeoJSON, запустить BUILD_DATABASE.cmd. Потребуется Python 3.9 или новее, только стандартная библиотека.
4. Результаты работы сборщика, диагностические файлы и RETURN ZIP должны сохраняться в той же папке, где расположен CMD.
5. В новом чате передать этот ZIP и текст NEXT_CHAT_PROMPT_RU.txt. Сначала читать документацию из папки doc/, затем data/data.json.
6. Не нужно повторно искать весь первоначальный архив PDF. Исходный многотомный ZIP пользователь просил игнорировать: все PDF были ранее загружены отдельными документами.

## Состав архива

site/index.html, site/r11-map.js, site/r11-map.css — сайт R11;
data/data.json — единственный полный JSON-снимок исследовательской базы;
data/*.csv — экспорт объектов, свидетельств, источников, документов, кладов, топонимов, геонавигации;
BUILD_R11.py, BUILD_DATABASE.cmd, OPEN_ATLAS.cmd — локальная сборка и просмотр;
SCHEMA_R11.sql — нормализованная схема SQLite;
doc/01_CURRENT_STATE_RU.md, 02_HISTORY_R01_R11_RU.md, 03_SCIENCE_AND_GEO_RU.md, 04_NEXT_STEPS_RU.md — подробная история, методика и продолжение;
NEXT_CHAT_PROMPT_RU.txt — точные инструкции для нового чата;
MANIFEST.json — список файлов и контрольные суммы.

Оригинальные 55 PDF в ZIP не включены: размер исходной библиотеки измеряется гигабайтами. Архив содержит извлечённую научную информацию и точные имена/ID документов, но не заменяет первоисточники для новых, ещё не прочитанных страниц.
