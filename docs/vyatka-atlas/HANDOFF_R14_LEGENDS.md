# R14 — Клады — легенды

Новая версия на основе GitHub R11: 151 исходная запись, 43 клада, 55 документов. `data.json`, `atlas-r11.html`, `index.html`, `r11-map.js` не изменены.

Новая вкладка `Клады — легенды (7)`: тематическая коллекция из 7 сообщений, включая проверенные страницы Спицына 1887 (PDF 48–50, печ. 44–46) и вторичную цитату Спицына 1882 (оригинал требует сверки).

Вкладка не добавляет вымышленных точек на карту, не меняет 151 реальный учётный маркер и не смешивает легенды с нумизматикой. Выбор легенды показывает карточку справа и переводит карту к широкому ориентиру; popup отсутствуют. Источник данных: `treasure-legends-r14.json`, та же коллекция встроена в `atlas-r14.html` для надёжной загрузки.

Публикация: `docs/vyatka-atlas/atlas-r14.html`. Старые публичные ссылки остаются на R11. Для окончательного обновления главного index требуется отдельная синхронизация после пользовательской проверки.
